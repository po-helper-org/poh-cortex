# Слой решений

Знание в `NEXUS/` отвечает на вопрос «что мы знаем». Этот слой отвечает на
вопрос, ради которого память вообще ведётся: **под что мы готовы подписаться**.

```
SCHEMA/ladder.yaml   по какой линейке меряем   ← меняется только на калибровке
evidence/            артефакты                 ← только добавление, правка запрещена
NEXUS/               знание, собранное из артефактов
bets/                обещания: порог, дата, зависимости, CP
decisions/           калибровки и решения квартала
log/                 наблюдения без артефакта: латентность, тишина. На CP не влияют
```

Движение одностороннее: поток → артефакт → знание → обещание. Обратно никогда:
статус в трекере в CP не попадает.

## Ставка

Обещание с порогом и датой. Три-семь на квартал; меньше трёх — декомпозиция
поверхностная. CP ставки равен минимуму CP её критических зависимостей: цель не
прочнее слабейшего звена.

## Артефакт

Файл в `evidence/` неизменяем. Артефакт можно добавить, нельзя переписать:
иначе история уверенности превращается в пересказ сегодняшнего мнения.
Ссылка нужна человеку, а не агенту — чтобы через полгода можно было проверить.

## Наблюдение

`log/` — то, что видно, но не подтверждено артефактом: смежник стал отвечать за
девять дней вместо двух. На уверенность не влияет, но показывает, где тишина.
