# Производные артефакты

Здесь лежит то, что инструмент может пересобрать из памяти: выгрузки отчётов,
очереди на разбор, экспорт для внешних систем. Ничего из этого не является
истиной — истина в `NEXUS/`, `DECIDE/` и `PULSE/`.

Правило простое: файл, который нельзя восстановить командой, здесь не место.
