# Производные артефакты

То, что инструмент пересобирает из памяти. Ничего здесь не является истиной —
истина в `NEXUS/`, `DECIDE/` и `PULSE/`. Правило простое: файл, который нельзя
восстановить командой, здесь не место.

```
packs/<профиль>.md    срез памяти под профиль: cortex pack --all
```

**Срезы коммитятся намеренно.** Профиль Hermes может не иметь ни шелла, ни
чекаута — файл в репозитории он прочитает в любом случае. Поэтому срез
пересобирается детерминированным прогоном и кладётся сюда, а не строится на
стороне профиля.

Отсюда следствие: срез в репозитории может отстать от памяти. Пересобирайте его
вместе с изменениями (`cortex pack --all`) — CI показывает расхождение.
