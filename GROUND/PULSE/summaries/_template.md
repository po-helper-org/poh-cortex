# Шаблон эпизода PULSE

Эпизод — след встречи: кто был, что решили, каких узлов Нексуса это касается.
Кладите файл рядом: `GROUND/PULSE/summaries/2026-01-15-planning.md`.

Эпизод живёт здесь же, в `GROUND/PULSE/summaries/`. Связи с памятью пишутся
полями: `nexus_links` — на узлы, `участники` — на людей. Ключи frontmatter
здесь **русские**: это формат эпизода, а не Node schema.

```yaml
---
дата: 2026-01-15
источник: transcript-2026-01-15-planning   # id записи/файла, если есть
участники: [team-ivanov-ivan, team-petrova-anna]   # node_id из Нексуса team
nexus_links: [seg-smb-retail, f-billing-export]    # node_id затронутых узлов
---
```

## Тело

```markdown
## Решения

- <что решили, кто владелец решения>

## Изменения контекста

- <какой узел устарел или подтвердился, каким источником>

## Открытые вопросы

- <что осталось без ответа и кто закрывает>
```

## Правила

- Ссылки на узлы — через `nexus_links` или `[[wiki-links]]` в теле; движок
  вытащит и то, и другое.
- Ключи задач вида `ABC-123` подхватываются автоматически и становятся
  `task`-узлами. Не выдумывайте ключи, которых нет в трекере.
- Эпизод — источник для обновления узлов, но сам узлы не обновляет.
  Решение из встречи попадает в Нексус только когда вы явно поправите узел
  и добавите эпизод в его `sources`.
