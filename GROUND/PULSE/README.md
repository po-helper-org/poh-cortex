# PULSE — операционный слой

След происходящего: встречи, дейлики, радары по чатам. Формат свободнее, чем у
узла: это не знание, а наблюдение с датой.

```
summaries/   эпизоды встреч
radar/       срезы «что горит сейчас» по чатам
daybook/     дни: что сделано, что не двинулось
```

**Эпизод сам узлы не обновляет.** Решение из встречи попадает в память, только
когда вы явно правите узел и добавляете эпизод в его `sources`. Иначе память
наполняется пересказами вместо фактов.
