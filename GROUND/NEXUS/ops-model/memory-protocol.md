# Протокол памяти

Семь правил. Нарушение любого из них ловится гейтом или превращает память в
документацию, которая гниёт.

1. **Один факт — один узел.** `.md` с YAML-frontmatter по схеме из
   `GROUND/SCHEMA/nodes.yaml`. Отсутствие обязательного ключа — ошибка гейта.

2. **`sources` обязателен.** Пусто = workslop, узел не считается. Источник —
   документ, интервью, аналитика, эксперимент, решение команды. Не «здравый смысл».

3. **Рёбра пишутся полями, не текстом.** Список полей — `SCHEMA/edges.yaml`.
   Связь, упомянутая только в тексте, графом не станет.

4. **Сначала узел, потом ссылка.** Ссылка на несуществующий `node_id` —
   висячее ребро, гейт падает. `node_id` не выдумывается «на будущее».
   Ключи трекера объявляются внешними в схеме, а не подставляются под узлы.

5. **Уверенность выводится, а не назначается.** Ступень 2–9 берётся из
   `SCHEMA/ladder.yaml` по самому сильному артефакту, который открывается по
   ссылке. Потолки: устное и чат ≤3, пересказ чужих слов ≤2. Повышение
   ступени требует **нового источника**; понижение — нормальная операция,
   а не поражение.

6. **Свежесть вычисляется.** `p = (сегодня − updated) / ttl_days`: `<0.5` fresh,
   `<1.0` ripening, `≥1.0` wilting. Срок годности выводится из `change_rate`
   объекта (`SCHEMA/profiles.yaml`), данных нет — `unknown`, то есть `high`.
   Увядание снимает ступени само: `bin/cortex refresh`. Wilting-узел
   **верифицируют или понижают ему CP** — дату без проверки не продлевают.

7. **Гейт перед коммитом.** `bin/cortex gate` — ноль ERROR. WARN про пустой
   `sources` у `_index` — это список ненаполненных Нексусов, он гаснет по мере
   онбординга.

## Кто пишет

`captured_by` в каждой записи: человек, детерминированный агент, навык или бот
сборщика. Зоны объявлены в `SCHEMA/agents.yaml` и проверяются гейтом. Сборщики
пишут только в `_intake/` и `DECIDE/log/`: поток становится знанием после
разбора, а не в момент поступления.

## Что делать с противоречием

Новый источник противоречит существующему узлу — **не затирать молча**:
обновить узел, указав оба источника, и зафиксировать в теле, что изменилось и
почему. Система не выбирает правильный источник: расхождение и есть
неопределённость, и оно понижает уверенность, а не повышает её.
