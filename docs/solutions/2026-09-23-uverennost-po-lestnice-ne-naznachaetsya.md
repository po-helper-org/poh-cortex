# Уверенность выводится по лестнице 2–9, а не назначается ощущением

## Ситуация

Раньше уверенность узла назначалась вручную долей (`confidence: 0.3`) — ощущением
автора. Ничто не мешало завысить ступень без доказательства, и ничто не снимало
устаревшую уверенность: знание «протухало» незаметно.

## Причина

Число, которое ставит человек, не связано ни с источником, ни со временем: у него
нет основания расти и причины падать. Правило, которое калибруют под желаемый
результат по ходу дела, перестаёт что-либо измерять.

## Решение

Уверенность — вывод из лестницы доказательности 2–9 (`SCHEMA/ladder.yaml`) с
потолками канала и полномочий: узел ссылается на артефакт (`cp`), ступень растёт
только с новым источником — инструмент отклоняет повышение без него. Распад по
профилю (`change_rate`) снимает ступени сам. Спор не решается выбором стороны:
`cortex conflicts` показывает обе стороны с источниками и правильную не выбирает —
расхождение понижает уверенность обеим, снять его можно только новым источником.
Итоги подводит `cortex calibrate`: срок годности против наблюдаемой частоты
изменений, лестница против исходов закрытых ставок, слепые зоны; правки в правила
вносит человек. Контур калибровки впервые прогнан на стенде из шести закрытых ставок
с `outcome`: инструмент сам нашёл переоценённую ступень — из четырёх обещаний
третьей ступени доехало одно.

## Как проверить

Дымовой тест и приёмка на чистом клоне (см. кейс схемы-как-данных); контур
калибровки — стенд с закрытыми ставками из теста сравнения (12/12); попытка поднять
ступень без нового источника отклоняется инструментом.

## Уроки

- Выводимая уверенность защищает от самообмана лучше назначаемой: повышение требует
  источника, понижение делает время автоматически.
- В споре данных «правильной стороны» нет: неопределённость понижает уверенность
  обеим, пока не придёт новый источник.
- Калибровка правил — данными, правки правил — человеком.
