# Несколько агентов в одной памяти — зоны записи, черновики и срезы

## Ситуация

Памятью должны одновременно пользоваться несколько ИИ-агентов разных владельцев
продукта в одной структуре. Шаблон прежней версии не отвечал: кто и куда имеет право
писать, что считать фактом, а что черновиком, и как агенту без исполнения команд
получить свою часть памяти.

## Причина

Одновладельческий vault: нет понятия зоны записи, приёмки записи и границы доверия
между агентами — координация жила бы в переписке, а не в памяти.

## Решение

- Профиль на каждого владельца (`CORTEX_PROFILE` / `--as`) со своей зоной. Три
  уровня: ядро `scope: org` — под куратором, изменения через PR; чужая зона — только
  чтение; своя зона — запись черновиками.
- Зоны пересекаются сознательно: у профиля список `writes`, совместное владение
  узлом — поле `shared_with`; пересечение фиксируется в памяти, а не в переписке.
- Всё написанное агентом — `status: draft` и не выдаётся как факт, пока человек не
  примет через `cortex review`: пачкой по Нексусу для онбординга, поштучно для
  фактов о людях.
- `cortex seams` показывает рёбра через границу зоны: наружу — с сортировкой по
  слабому звену, внутрь — с предупреждением, что понижение уверенности ударит по
  чужой части. Слабейшая ступень на чужой стороне — потолок обещания.
- `cortex pack` собирает срез памяти под профиль — для агента, который не исполняет
  команды или не вместит всю память; CI проверяет, что срезы не отстали.
- `captured_by` и зоны из `SCHEMA/agents.yaml` проверяет гейт: запись мимо зоны —
  ошибка, а не стиль.

## Как проверить

Полный жизненный цикл на клоне: настройка → профили и зоны → новый Нексус → запись
от двух профилей → приёмка → резолвер → стыки → повестка → цели → расхождение между
зонами → срез → пересчёт → калибровка. Гейт: профиль не пишет в ядро; команды
чтения не изменили ни байта.

## Уроки

- Права записи проверяет гейт, а не договорённости: «запись мимо зоны — ошибка, а не
  стиль».
- Черновик по умолчанию с приёмкой человеком — единственный способ доверять памяти,
  в которую пишут автоматы.
- Срезы для слабых агентов — артефакт CI: без пересборки они начинают врать.
