# Движок памяти: оцифровка Нексуса

[poh-memory-engine](https://github.com/po-helper-org/poh-memory-engine) читает
этот vault и превращает markdown в граф: выводит типизированные рёбра из
frontmatter, считает Context Ripeness, ловит висячие рёбра и протухшие узлы.

Markdown в git — носитель истины. Граф и вектор — **пересобираемые артефакты**:
их можно выбросить и построить заново из тех же файлов.

## Подключение

```bash
./scripts/cortex.sh engine
```

Клонирует движок в `.engine/` (в `.gitignore`) и добавляет его в `PYTHONPATH`.
Все остальные команды подтягивают его сами, если его ещё нет.

Свой форк движка: `CORTEX_ENGINE_URL=https://github.com/<вы>/poh-memory-engine`.

## Команды

| Команда | Что делает | Пишет в vault |
|---|---|---|
| `gate` | схема config + registry, Node schema, висячие рёбра, дрейф свежести | нет |
| `report` | узлы, рёбра, Context Ripeness по Нексусам, очередь неразрешённых owner | нет |
| `gaps` | дыры, достижимость value-контента от хребта KR, узлы без ценностного ребра | очередь кандидатов |
| `build` | генерирует узлы `objective`/`key-result` из KR-карты и `episode` из PULSE, записывает рёбра в frontmatter | **да** |

`build` — единственная команда, меняющая узлы. Она перезаписывает
`GROUND/NEXUS/okr/` и `GROUND/NEXUS/pulse/`: править их руками бессмысленно.

## Окружение

Скрипт выставляет сам, переопределяется переменными:

| Переменная | Значение по умолчанию |
|---|---|
| `POH_VAULT` | корень репозитория |
| `POH_QUARTER` | текущий квартал из даты (`q3-2026`) |
| `POH_DEFAULT_OWNER` | `team.roster.product_engineer` из `config.yaml` |
| `CORTEX_ENGINE_DIR` | `.engine` |
| `CORTEX_ENGINE_URL` | `https://github.com/po-helper-org/poh-memory-engine` |

## Что показывает свежий клон

| Метрика | Значение | Почему так |
|---|---|---|
| ошибок гейта | 0 | шаблон валиден с первого дня |
| предупреждений | 6 | по одному на ненаполненный Нексус — это ваш список работ |
| узлов | 10 | 7 MOC-заглушек + 3 узла методологии |
| Context Ripeness | 0.0 везде, кроме `ops-model` | контекста организации ещё нет |
| достижимость от хребта KR | 0% | хребет OKR пуст, целей квартала нет |

Цифры начинают расти с первого реального узла. Нулевая спелость на старте —
не поломка, а честное «памяти ещё нет».

## Фазы Кортекса

| Фаза | Что работает |
|---|---|
| 1 | ИИ-агент читает frontmatter напрямую из vault; гейт в CI |
| 2 | поверх добавляется индексация и семантический поиск по узлам |

Целевая фаза задаётся в `GROUND/config.yaml` → `cortex.phase_target`.
