# Гейт памяти

```sh
bin/cortex gate          # ноль ERROR — обязательное условие коммита
bin/cortex gate --all    # полный список находок
bin/cortex gate --json   # для разбора агентом
```

Проверяет по схеме из `GROUND/SCHEMA/`: обязательные ключи по слою и типу,
`nexus` из реестра, объявленность типа узла, enum-значения, непустой `sources`,
диапазоны `cp` и `confidence`, целостность рёбер, дубликаты `node_id`,
дрейф вычисляемой свежести, зоны записи агентов и дрейф реестра.

## Как читать вывод

| Сообщение | Что делать |
|---|---|
| `нет обязательного ключа` | дописать из `_template.md` соответствующего Нексуса |
| `nexus 'x' нет в реестре` | `bin/cortex nexus add x` — объявить объект управления |
| `node_type 'x' не объявлен` | добавить в `node_types` у Нексуса в `_registry.yaml` |
| `Нексус не объявлен в _registry.yaml` | папка с узлами живёт мимо реестра — объявить |
| `висячее ребро` | создать узел или убрать ссылку. **Не подменять похожим id** |
| `дубликат node_id` | слить узлы, оставить один |
| `пустой sources` | источник или удаление узла |
| `ripeness=…, вычисляется …` | `bin/cortex refresh` — это несделанный пересчёт, а не мнение |
| `агент … не имеет права писать сюда` | запись мимо зоны из `SCHEMA/agents.yaml`: разобрать через `_intake/` |
| `нет captured_by` | проставить, кто записал: человек, навык или бот |

## Чем чинить нельзя

- Ослаблять схему, удалять требование источника, глушить проверку.
- Продлевать `updated`, чтобы убрать увядание: узел верифицируют **или**
  понижают ему CP.
- Заменять висячий `node_id` на похожий существующий «чтобы прошло».
- Переводить проверку в `off` в `GROUND/SCHEMA/checks.yaml`, чтобы убрать
  красное: этот каталог агенту закрыт, и ослабление проверки — решение
  человека о своём контуре, а не способ закрыть находку.

Красный гейт означает, что память сломана, а не что проверка мешает.
