# Гейт памяти

```bash
./scripts/cortex.sh gate
```

Проверяет: структуру `config.yaml` + `_registry.yaml`, обязательные ключи Node
schema, `nexus` из реестра, валидность `node_type`/`kind`/`confidence`/`ripeness`,
непустой `sources`, целостность рёбер и дрейф свежести.

## Как читать вывод

| Сообщение | Что это | Что делать |
|---|---|---|
| `ERROR: отсутствует обязательный ключ` | узел не по Node schema | дописать ключ из `_template.md` |
| `ERROR: nexus 'x' нет в _registry.yaml` | Нексус не зарегистрирован | `/paf-nexus-create` или исправить значение |
| `ERROR: … висячее ребро` | ссылка на несуществующий `node_id` | создать узел или убрать ссылку — **не подменять похожим id** |
| `ERROR: дубликат node_id` | два файла с одним id | слить узлы, оставить один |
| `ERROR: пустой sources (workslop)` | узел без источника | добавить источник или удалить узел |
| `WARN: пустой sources (MOC-заглушка)` | Нексус не наполнен | это список работ онбординга, не поломка |
| `WARN: ripeness=…, но сейчас …` | дрейф свежести | привести `ripeness` к вычисленному |
| `WARN: узел wilting` | протух по `ttl_days` | верифицировать источником **или понизить CP** |
| `ПЛЕЙСХОЛДЕРЫ` | остались `< >` из шаблона | заполнить или `./scripts/cortex.sh init` |

## Чем чинить нельзя

- Удалять `sources`-требование, ослаблять схему, глушить проверку.
- Продлевать `updated` без проверки источника, чтобы убрать wilting.
- Заменять висячий `node_id` на похожий существующий «чтобы прошло».
- Правит руками узлы в `okr/` и `pulse/` — их перегенерирует `build`.

Гейт красный означает, что память сломана, а не что проверка мешает.
