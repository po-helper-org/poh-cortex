# Узел: создать или обновить

## Перед записью

```sh
bin/cortex ask "<о чём узел>"    # нет ли уже такого — дубликат хуже пропуска
```

## Создать

```sh
bin/cortex node new --nexus <slug> --type <тип> --title "<заголовок>" \
  --source "<источник>" --cp <2..9> --change-rate <high|medium|low|unknown> \
  --owner "<владелец>" --by <кто записывает> --dry-run
```

Сначала **всегда** `--dry-run`: покажите человеку, что будет записано, и
дождитесь подтверждения. Затем тот же вызов без флага.

Инструмент откажет сам, если Нексуса нет в реестре, тип не объявлен, источника
нет, `node_id` занят, заголовок похож на существующий узел или `satisfies`
указывает в пустоту. Это не препятствие, а контракт: он же избавляет от
необходимости помнить схему наизусть.

| Аргумент | Правило |
|---|---|
| `--source` | обязателен и конкретен: `interview:CPO 2026-02-11`, `analytics:cohort-q1`, `evidence/2026-09-12-letter` |
| `--cp` | ступень из `SCHEMA/ladder.yaml` по самому сильному артефакту. Устное ≤3, пересказ ≤2 |
| `--change-rate` | из истории изменений объекта. Не знаете — `unknown`, он трактуется как `high` |
| `--scope` | зона: `org`, `team:<имя>`, `product:<имя>`. По умолчанию — зона Нексуса |
| `--satisfies` | привязка к цели квартала; только на существующий `node_id` |

Нужного типа нет — объявите его у Нексуса в `_registry.yaml` (`node_types`).
Нужного Нексуса нет — `/paf-nexus-create`. Схема расширяется, а не обходится.

## Обновить

```sh
bin/cortex node set <node_id> --cp 6 --source "<новый артефакт>"
```

Повышение ступени **требует нового источника** — без него инструмент откажет.
Это не формальность: уверенность без артефакта и есть то, от чего защищает
вся конструкция. Понижение CP — нормальная операция, а не поражение.

Противоречие между источниками — сохраните оба и опишите в теле, что
изменилось. Не выбирайте правильный источник сам: расхождение и есть
неопределённость.

## Не делать

- Не менять `node_id` существующего узла: это рвёт все рёбра на него.
- Не ставить `ripeness` руками — его считает `bin/cortex refresh`.
- Не писать в чужую зону, объявленную `shared: false`.
